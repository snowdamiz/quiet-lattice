Capacity calculation (allocation.json contains unrounded values)

At 512 px/m one 4096² tile covers 64 m² if every texel is uniquely allocated.
345.212 m² needs 5.39394 tile areas. Perfectly packing one unique tile would
reach only 220.453 px/m across that area. The current Hull needs 4.52087 times
the linear UV density, or 20.43825 times its current UV area. Merely packing
more tightly, enlarging pixels, scaling/repeating the old noise, or changing
the validator cannot solve this. Absolute triangle area includes layered
surfaces; no unseen/back faces are silently omitted to improve the number.

Method and prepared checker

measure_export.cjs is adapted from the pinned authoritative audit. It reads the
actual compressed GLB after explicit release, with installed NodeIO and the
registered synchronous MeshoptDecoder. It reads KTX2 headers without image
transcoding. No fetch/install path is provided. It uses the whole ancestor
world matrix, declared component types/strides/offsets and normalized accessor
semantics. Raw buffer-view decode sample checks remain. Sparse attributes,
animated/skinned/morph poses and external buffers/images fail explicitly.

For each triangle and texture binding:
  Aw = world-space triangle area in square metres.
  Auv = absolute UV area after KHR_texture_transform.
  density = sqrt(width * height * Auv / Aw).
Use KHR_texture_transform.texCoord over textureInfo.texCoord over 0.
Signed normalized minima clamp to -1; unsigned normalize by 255/65535. Compute
integer-lattice edge cross products followed by the world linear cofactor and
normalization divisors. This preserves exact quantized collinearity without
an epsilon or translated-float cancellation. Texture scale determinant affects
area; rotation/offset affect reported bounds but not area.

Exclude exact zero-world-area triangles with an explicit inventory. Retain
positive-world/zero-UV triangles at zero density with their physical weight.
Report per primitive/material/binding and per texture slot; unlike a combined
binding aggregate, different color/normal UV assignments cannot double-count
physical area or hide a low-density channel. Area-equivalent RMS, area-weighted
mean, physical-area percentiles and descriptive bins all remain distinct.
Double-sided materials do not double the physical area. Exclude COL/REF
hierarchies and untextured constant/emissive surfaces, listing their reasons.

Default pins select all nine LOD0 state/livery roots. Later make a separate
pin file for LOD1/2/3 comparison; never overwrite the preserved baseline pins.
After parent release, run via run.py measure --parent-released-export-decode
--pins <new exact candidate pin file> --label <new unique label>. The flag is a
guard against accidental execution, not parent authorization by itself.
Fresh actual-export execution of this adapted checker is STILL HELD. Analytic
fixtures and a syntax check do not establish library integration, 9-root runtime
memory, or successful measurement of the saved blend. The upstream audit is
