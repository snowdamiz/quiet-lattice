# Packet storage contract

The CPU unit remains disabled. These are source guarantees for independent review, not a successful native integration result.

`packet-budget.mjs` and `packet_budget.py` enforce one packet metadata ceiling of33,554,432bytes and256files. The only non-metadata file is `capture/primary.mp4`, limited separately to536,870,912bytes by the encoder's inherited `RLIMIT_FSIZE`. Every other packet file, including complete observations, frame maps, encoder reports, validator raw-output copies, indices, temporary writes and terminal records, counts toward the metadata ceiling. The independent caller inspector repeats the whole-packet byte/count check and requires the listed capture/validator files.

Two128KiB files are reserved: `failure.json` and `integration-result.json`. Ordinary writers may consume at most32MiB minus256KiB and leave both reserved file slots plus an absent media slot available. `failure.json` is exclusive and keeps the first failure. The final record is also exclusive. Large terminal details remain exact in the private summary and are referenced by SHA-256 from a bounded HOLD record; native job observations remain exact in their separately hashed private receipts. This changes references, not the complete frame observations.

Before a controlled normal write, the gate counts the current packet plus all incoming bytes. Atomic replacement counts the old target and the complete temporary file together. A prospective file is counted before opening it. A failed or partial write is retained, and the inspector refuses an interrupted `.writing` artifact. **Permitted packet metadata or file-count overshoot: zero.** There is no whole-volume quota or new ownership service.

The entry checks space for its next observation/manifest work before dispatch and awaits each frame's encoder acknowledgment. Every actual observation and JSON write still goes through the gate. Overflow holds the unit before further dispatch; the reserved failure record preserves the primary failure. Complete non-image fields, including unknown fields, keep their256KiB per-frame allowance. Required still PNG behavior is unchanged.

During encode, Node owns packet metadata writes. Python's encoder command/result files remain explicit private evidence, each capped by the existing2MiB report bound; Node copies them only after checking the packet gate. The encoder and its raw combined stdout/stderr file retain the existing512MiB per-file OS bound. Node's raw worker ACK/error logs are private evidence. No PNG payload or video copy staging is added.

After producer release, the validator is the sole normal packet writer. Each native stdout/stderr stream starts in an explicit private evidence file under the existing2MiB per-file OS bound. It then copies exact bytes through the packet gate. Three native phases therefore have at most12MiB of raw stdout/stderr before packet copies; commands and error reports have the existing2MiB per-file JSON cap. Native outputs and partial failures remain private if packet admission fails. No raw RGB reel is written.

The parent writes the bounded terminal packet record after drain/audit. It references complete private job receipts instead of duplicating their observation arrays. This preserves the first failure, distinct cleanup results, actual child identities and post-read facts while bounding packet growth.

Private StationJob archives, controller logs, profile/cache preservation and free space are **observed** at the unchanged release/cleanup boundary. The1GiB per-job archive figure is an acceptance ceiling, not an OS quota or a hard bound on every helper/cache write. Exceeding it holds the unit and preserves all bytes. Atomic controller-receipt replacement and LFS clean staging are outside the packet and remain charged to the separate1GiB staging allowance. Native per-file bounds are enforced; a fixed maximum overshoot for the combined shared-helper/cache archive is not claimed. The unused1GiB archive-slot reserve and4GiB safety floor remain accounted, and a new native grant still needs current admission and independent source review. No whole-library fit or complete hard filesystem quota is claimed.
