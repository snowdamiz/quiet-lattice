DECODE / MAPPING / MATH
Installed Node v22.23.3, @gltf-transform/core 4.5.1 and extensions 4.5.1, meshoptimizer 1.3.0. The NodeIO registration/read/getElement/getWorldMatrix route follows the proven Lark decoder. The meshopt decoder itself is the installed, unchanged dependency. A second implementation uses the previously exercised Swift raw buffer-view decode / column-major TRS composition route. Both use meshopt count, byteStride, byteOffset, mode, and filter; integer values are never reinterpreted as float32.

Signed normalized BYTE/SHORT = max(raw/127 or raw/32767, -1). Unsigned normalized BYTE/SHORT = raw/255 or raw/65535. Float attributes stay float. Index buffers are read according to their declared types and stride. Actual selected POSITION accessors are normalized signed int16; TEXCOORD_0 accessors are normalized uint16. 24 unique position/UV accessors have explicit raw/normalized/NodeIO samples in density.json. All 30 mapped primitives are independently decoded in crosscheck.json.

For each triangle, use the complete ancestor world matrix, including node quantization scales. Base Body world scale is 7.390239953994751 on each axis; it is not unit scale. Full world matrices and paths are preserved per primitive. World cross products are computed from exact signed-clamped integer-domain position differences, divided by the normalization denominator squared and multiplied by the world linear cofactor matrix. This is algebraically the same as transforming triangle edges, handles nonuniform scale and shear, and avoids translation-cancellation artifacts on collinear quantized triangles. UV determinants likewise use exact integer-domain values and the normalization divisor. No small-area epsilon discards real triangles.

Each texture slot selects KHR_texture_transform.texCoord when provided, otherwise textureInfo.texCoord, otherwise zero. UV transform is offset + R(rotation) * diag(scale) * UV; its area multiplier is abs(scale.x * scale.y). Actual selected maps all use TEXCOORD_0 and no KHR_texture_transform. All image dimensions come from the embedded KTX2 headers, not filenames or material extras. The GLB contains 13 images, all 4096 x 4096 with 13 levels. No pixel payload is decoded. All four mapped slots (base color, metallic/roughness, normal, occlusion) have the same dimensions and UV transform per material, so their densities are identical and are measured once per equivalent binding.

A_w = ||(P1_world-P0_world) x (P2_world-P0_world)|| / 2 square metres.
A_uv = abs(det(U1_transformed-U0_transformed, U2_transformed-U0_transformed)) / 2.
Triangle density d = sqrt(W * H * A_uv / A_w) px/m.
Area-equivalent density = sqrt(sum(W * H * A_uv) / sum(A_w)): the world-area-weighted RMS of triangle densities.
Area-weighted mean = sum(A_w * d) / sum(A_w).
Weighted percentiles are inverse cumulative physical area after sorting triangle density. Count percentiles use floor((n-1)*p), also retained in JSON. All areas are sums of triangle areas, not UV union occupancy; layered surfaces count separately. Double-sided material rendering does not double physical geometric area. This scalar area metric does not assess directional anisotropy, texture content, visibility, or pixel quality.
